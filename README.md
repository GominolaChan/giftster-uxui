# Giftster — Rediseño de la pantalla de perfil

Proyecto de UX/UI realizado como parte del **Sprint 9 · Proyecto 4** de mi formación en TripleTen.

El trabajo reúne el rediseño de la pantalla de perfil de Giftster y la documentación visual de sus principales decisiones de interfaz: estructura, tipografía, paleta de color y componentes.

> **Proyecto de diseño:** este repositorio documenta el proceso y el resultado en Figma. No contiene una aplicación web ni código de producción.

## Vista general

La propuesta presenta una pantalla de perfil para Giftster, una experiencia centrada en listas de regalos y preferencias personales. La interfaz incluye una cabecera de perfil, acceso a listas de regalos, preferencias y amigos, además de acciones de cuenta.

![Portada del proyecto Giftster](assets/cover.png)

## Qué encontrarás en el archivo de Figma

- **Portada:** presentación e índice del proyecto.
- **Diseño:** pantalla final, comparación del antes y el después y notas de diseño.
- **Tipografía:** estilos de texto y jerarquía de la información.
- **Colores:** paleta cromática y contrastes.
- **Componentes:** botones, etiquetas, tarjetas e iconos.
- **Borradores:** análisis de la pantalla original, iteraciones y pruebas.

## Dirección visual

La propuesta utiliza una identidad colorida y amable, con una base de índigo y tonos claros, acompañada de acentos cian, magenta y amarillo.

| Token / uso | Color |
|---|---|
| Índigo principal | `#2B1B5A` |
| Cian | `#2EC4C6` |
| Magenta vivo | `#E6397A` |
| Amarillo | `#FFC93C` |
| Fondo crema | `#FFF8F0` |
| Lavanda | `#EDE6FA` |
| Texto principal | `#1F1536` |

**Tipografía:** Inter.
